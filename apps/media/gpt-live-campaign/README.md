# Natural Voice Access campaign

This directory contains the approved bilingual campaign source materials for SozoRock Health Natural Voice Access.

The scenario is illustrative and non-clinical. It demonstrates how a person can describe a request and continue through the appropriate user-facing channel. It does not represent a confirmed provider match, completed service, or verified local result.

## Source materials

- `campaign.json` contains the approved timing and dialogue structure.
- `script-en.md` contains the approved English reader script.
- `script-es.md` contains the approved Spanish reader script.
- `storyboard.md` contains the approved visual sequence.

Public releases must use approved source materials and pass the repository's release checks before publication.
